Roboter-Manipulatoren transformieren Gelenkwinkel in räumliche Werkzeugkoordinaten. In dieser interaktiven Anleitung analysieren wir die Vorwärtskinematik eines zweigliedrigen planaren Roboterarms anhand mathematischer Herleitungen, Vektordiagrammen und Echtzeit-Codeausführung im Browser.

1. Mathematische Formulierung

Betrachten wir einen planaren Roboterarm mit den Gelenkwinkeln $\theta_1, \theta_2$ und den Armlängen $l_1, l_2$. Die kartesischen Koordinaten $(x_1, y_1)$ des Ellbogengelenks und $(x_{ee}, y_{ee})$ des Endeffektors ergeben sich trigonometrisch:

$$\begin{aligned} x_1 &= l_1 \cos(\theta_1) \ y_1 &= l_1 \sin(\theta_1) \ x_{ee} &= l_1 \cos(\theta_1) + l_2 \cos(\theta_1 + \theta_2) \ y_{ee} &= l_1 \sin(\theta_1) + l_2 \sin(\theta_1 + \theta_2) \end{aligned}$$

Wie von John J. Craig in seinem Standardwerk [craig2005] beschrieben, bildet die Darstellung über homogene Transformationsmatrizen das Fundament für Manipulatoren mit höheren Freiheitsgraden.

4. Direkte Einbindung von Quellcodedateien

kinematics.py
python
import numpy as np

def forward_kinematics(theta1_deg, theta2_deg, l1=1.0, l2=0.8):
    """
    Computes end-effector (x, y) coordinates for a 2-DOF planar robotic arm.
    :param theta1_deg: Base joint angle in degrees
    :param theta2_deg: Elbow joint angle in degrees
    :param l1: Length of link 1 (meters)
    :param l2: Length of link 2 (meters)
    """
    t1 = np.deg2rad(theta1_deg)
    t2 = np.deg2rad(theta2_deg)
    
    x1 = l1 * np.cos(t1)
    y1 = l1 * np.sin(t1)
    
    x_ee = x1 + l2 * np.cos(t1 + t2)
    y_ee = y1 + l2 * np.sin(t1 + t2)
    
    return (x1, y1), (x_ee, y_ee)

if __name__ == "__main__":
    elbow, ee = forward_kinematics(45.0, 30.0)
    print(f"Elbow Joint Position:  x={elbow[0]:.4f} m, y={elbow[1]:.4f} m")
    print(f"End-Effector Position: x={ee[0]:.4f} m, y={ee[1]:.4f} m")
