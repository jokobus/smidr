Datenschutzerklärung

📅 01. Jan 2026 ⏱️ ~1 Min. Lesezeit (139 Wörter)

1. Datenschutz auf einen Blick

Wir nehmen den Schutz Ihrer persönlichen Daten sehr ernst. Diese Website folgt dem Prinzip der Datensparsamkeit:

  • Keine Tracking-Cookies: Es werden keine profilbildenden Cookies auf Ihrem Endgerät gespeichert.
  • Kein Google Analytics: Es werden keine Daten an Werbenetzwerke übertragen.
  • Ausschließlich clientseitige Ausführung: Alle interaktiven Code-Umgebungen (WebAssembly/Pyodide) laufen isoliert in Ihrem lokalen Webbrowser. Es werden keinerlei Code-Eingaben an unseren Server übertragen.

2. Datenschutzfreundliche Webanalyse (Umami)

Diese Website setzt Umami Analytics ein, eine quelloffene, datenschutzkonforme Analyselösung:

  • Verwendet keine Cookies und speichert keine personenbezogenen Identifikatoren.
  • IP-Adressen werden anonymisiert.
  • Daten werden nicht an Dritte weitergegeben oder seitenübergreifend verknüpft.

3. Server-Logdateien

Beim Aufruf unserer statisch ausgelieferten Webseiten werden durch den Webserver (z. B. Caddy auf einem Raspberry Pi oder GitHub Pages) standardmäßige Verbindungsdaten (z. B. aufgerufene URL, Datum und Uhrzeit, Browsertyp) temporär in Logdateien erfasst, um den störungsfreien Betrieb zu gewährleisten.
