One of the defining innovations of modern technical blogging is allowing readers to tweak parameters, verify equations, and run algorithms directly on the page.

In this dispatch, we demonstrate how Smidr utilizes WebAssembly (Pyodide) to execute code exclusively in the reader’s local web browser.

💡
Server Security & Resilience Guarantee
Because this static site is hosted on a Raspberry Pi (or GitHub Pages), zero code is ever transmitted to or executed on the server. All Python scripts run in an isolated client-side WebAssembly sandbox. Infinite loops or intensive computations only impact the reader’s local thread and cannot crash or breach the host server.
