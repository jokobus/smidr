Robotic manipulators transform actuator joint angles into spatial tool coordinates. In this interactive guide, we analyze the forward kinematics of a two-link planar robotic manipulator using mathematical derivations, vector diagrams, and real-time in-browser code execution.

1. Mathematical Formulation

Consider a two-link planar arm with joint angles $\theta_1, \theta_2$ and link lengths $l_1, l_2$. The Cartesian coordinates $(x_1, y_1)$ of the elbow joint and $(x_{ee}, y_{ee})$ of the end-effector are governed by trigonometric projection:

$$\begin{aligned} x_1 &= l_1 \cos(\theta_1) \ y_1 &= l_1 \sin(\theta_1) \ x_{ee} &= l_1 \cos(\theta_1) + l_2 \cos(\theta_1 + \theta_2) \ y_{ee} &= l_1 \sin(\theta_1) + l_2 \sin(\theta_1 + \theta_2) \end{aligned}$$

As established by John J. Craig in his foundational robotics treatise [craig2005] , representing these geometric transforms as homogeneous matrices provides computational uniformity for higher degrees of freedom.

import numpy as np

def forward_kinematics(theta1_deg, theta2_deg, l1=1.0, l2=0.8):
    """
    Computes end-effector (x, y) coordinates for a 2-DOF planar robotic arm.
    :param theta1_deg: Base joint angle in degrees
    :param theta2_deg: Elbow joint angle in degrees
    :param l1: Length of link 1 (meters)
    :param l2: Length of link 2 (meters)
    """
    t1 = np.deg2rad(theta1_deg)
    t2 = np.deg2rad(theta2_deg)
    
    x1 = l1 * np.cos(t1)
    y1 = l1 * np.sin(t1)
    
    x_ee = x1 + l2 * np.cos(t1 + t2)
    y_ee = y1 + l2 * np.sin(t1 + t2)
    
    return (x1, y1), (x_ee, y_ee)

if __name__ == "__main__":
    elbow, ee = forward_kinematics(45.0, 30.0)
    print(f"Elbow Joint Position:  x={elbow[0]:.4f} m, y={elbow[1]:.4f} m")
    print(f"End-Effector Position: x={ee[0]:.4f} m, y={ee[1]:.4f} m")
