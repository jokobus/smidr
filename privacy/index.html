1. General Notice & Data Protection Overview

We take the protection of personal data very seriously. This website is engineered with a strict privacy-first architecture:

  • No tracking cookies: We do not store or read tracking cookies on your device.
  • No Google Analytics: We do not transmit browsing profiles to advertising networks.
  • Client-Side Execution Only: All code playgrounds (Pyodide WebAssembly, JavaScript runners) run purely within your browser sandbox; no user code or telemetry is transmitted back to our server.

2. Privacy-Friendly Analytics (Umami)

This website uses Umami Analytics, an open-source, privacy-preserving web analytics solution:

  • It does not track visitors across websites or create cross-device profiles.
  • IP addresses are anonymized and never stored in raw form.
  • No personal identifying information (PII) is harvested.

3. Server Log Files

When visiting our site served from our static infrastructure (or GitHub Pages), minimal technical metadata (such as HTTP status codes, browser user-agent, and requested file path) may be processed in temporary web server logs for security and diagnostic purposes.
